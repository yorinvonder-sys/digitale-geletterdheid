# SEO

Deze folder bevat de publieke landingspagina's die op zoekverkeer gericht zijn: uitleg over digitale geletterdheid, SLO-kerndoelen, vergelijkingspagina's, gidsen en de compliance-hub.

Belangrijke ingangen:

- `DigitaleGeletterdheidVo.tsx`
- `SloKerndoelen.tsx`
- `SloRapport.tsx`
- `ComplianceHub.tsx`
- `ComparisonPage.tsx`
- `GuidePage.tsx`
- `src/app/AppRouter.tsx`

Alle pagina's hangen als lazy route in `src/app/AppRouter.tsx`. Zie `CLAUDE.md` in deze folder voor het vereiste model- en denkniveau.

Deze pagina's doen inhoudelijke uitspraken richting scholen over dekking, compliance en regelgeving. Behandel elke wijziging aan zo'n claim als Rood: onderbouw met `docs/compliance/regulations/` en laat juridische of beleidsmatige teksten bevestigen vóór publicatie.
